## Key Behaviors

- The **AI Advisory** panel is generated by the `coach_review` prompt/capability (Coach-facing, distinct tone from Member-facing text) — see [prompts/coach-review.txt](../prompts/coach-review.txt).
- **Setujui/Tolak** call `POST /coach/recommendations/{id}/approve` or `/reject`; approving sets `ai_recommendations.status=applied` and `reviewed_by`, which then surfaces to the Member as a "Program updated" note (transparency principle).
- **Catatan Pribadi** defaults `is_visible_to_member=false`; a Coach can flag an individual note visible via a toggle on that note.
- **Program tab** lets the Coach view and, if needed, directly edit the current meal/workout plan (creates a plan version with `source=coach`).
